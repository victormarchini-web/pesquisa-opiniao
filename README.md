# 📊 Pesquisa de Opinião - TudoWeb

## 📌 Sobre o projeto

Este projeto foi desenvolvido em Python para realizar uma pesquisa de opinião sobre o atendimento ao cliente da empresa fictícia TudoWeb.

O programa coleta informações de 50 entrevistados, como nome, idade e opinião sobre o atendimento.

As opções de avaliação são:

- ⭐ 1 - EXCELENTE
- 👍 2 - BOM
- 👎 3 - RUIM

Ao final da pesquisa, o programa apresenta a quantidade de respostas classificadas como **EXCELENTE** e **RUIM**.

## 🐍 Tecnologias utilizadas

- 🐍 Python
- 💻 Visual Studio Code
- 🔧 Git
- 🌐 GitHub

## 🔄 Funcionamento

O programa utiliza uma estrutura de repetição `for` para realizar a pesquisa com 50 entrevistados.

Para cada entrevistado, são solicitados:

- Nome
- Idade
- Opinião sobre o atendimento

Também são utilizadas estruturas de decisão `if` e `elif` para verificar a opinião informada.
